--- Library Management System ---

The Library Management System is a simple web-based application developed using Java, Servlets, and JDBC. It provides a basic digital solution for storing and viewing book records instead of maintaining manual registers. This project demonstrates the core concepts of Java Web Development, database connectivity, and request–response handling using the Apache Tomcat server.

Features :

Add Book
Allows users to enter book details such as ISBN, Title, Author, and Price through a form. The data is processed by a Servlet and stored in the database using JDBC insert operations.

View Books
Displays all stored books in a table format on a web page. This module retrieves data from the database using select queries and shows it dynamically to the user.

Technologies Used :

Java – Core application logic
Servlets – Handle client requests and responses
JDBC – Database connectivity and SQL operations
HTML / CSS – User interface design
Apache Tomcat – Server for deployment
MySQL / Oracle – Database for storing book data

Purpose :

The main purpose of this project is to understand the basics of Java web application development using Servlets and JDBC.
It also helps in learning database operations and deploying applications on a web server like Tomcat.
